Place Blender **Eevee** PNG screenshots here for side-by-side comparison with the R3F viewport.

## Matching the R3F scene

- Same camera framing as the Canvas default (`position ≈ [2.5, 1.8, 3.5]`, FOV 45)
- Same HDRI: `public/hdri/studio.hdr`
- Same exposure / AgX view transform as the app defaults
- Prefer DamagedHelmet (or mid-gray / glass) matching the subject picker

See `docs/reference/parity-checklist.md` for the full A/B checklist.
